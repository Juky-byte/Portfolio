Proyectos

Portfolio Web ▾

Proyecto personal de portfolio desarrollado para la materia Programación Web, enfocado en diseño moderno e interactividad.

Contexto y desafíos: El objetivo fue integrar maquetación semántica, variables CSS para temas dinámicos y algoritmos de manipulación del DOM en JS sin depender de librerías externas.
