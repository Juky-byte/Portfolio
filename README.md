
# 🚀 Portfolio Personal - Desarrollador Web

¡Bienvenido/a a mi repositorio de portfolio personal! Este proyecto fue desarrollado como parte de mi formación en desarrollo web, aplicando buenas prácticas de maquetación, estilos modernos, interactividad con JavaScript y un diseño totalmente responsivo.

---

## 🛠️ Tecnologías y Herramientas Utilizadas

* **HTML5:** Estructuración semántica del contenido (Header, Main, Section, Footer, Formularios).
* **CSS3:** Estilos avanzados, variables CSS (`:root`), sistema de temas Claro/Oscuro, Flexbox, CSS Grid y Media Queries.
* **JavaScript (ES6+):** Interactividad dinámica, consumo de APIs asíncronas, manipulación del DOM y validación de formularios.
* **Tipografías Personalizadas:** Implementación de fuentes locales mediante `@font-face` (*Poppins* y *Orbitron*).

---

## ✨ Características Principales

1. **Diseño Responsivo:** Adaptado fluidamente a dispositivos móviles, tablets y escritorios mediante *Media Queries*.
2. **Modo Claro / Oscuro:** Sistema de cambio de tema dinámico integrado con variables de color.
3. **Fondo Dinámico:** Efecto visual de polígonos geométricos flotantes con animaciones CSS.
4. **Sección de Proyectos (CSS Grid):** Cuadrícula adaptable de 3 columnas que se convierte en una sola columna en celulares, con tarjetas interactivas.
5. **Sección Interactiva (API):** Consumo de recursos externos mediante JavaScript.
6. **Formulario de Contacto:** Campos estructurados con validaciones y adaptabilidad táctil.

---

## 📂 Estructura del Proyecto

```text
/

```

---

## 📱 Vista Previa Responsiva

El sitio cuenta con adaptabilidad completa para garantizar una experiencia de usuario óptima en cualquier pantalla:
* **Escritorio:** Visualización en grilla múltiple con menús distribuidos de forma equitativa.
* **Móviles (< 768px):** Apilamiento vertical automático de contenidos, menú optimizado y elementos táctiles cómodos.
